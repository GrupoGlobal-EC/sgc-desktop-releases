# Sistema Global Courier · Descargas

Instaladores oficiales de Grupo Global para Windows de 64 bits.
Este repositorio distribuye paquetes; el codigo fuente se mantiene en un repositorio privado.

[Pagina de descargas](https://grupoglobal-ec.github.io/sgc-desktop-releases/)

| Ambiente | Descargar | Versiones |
| --- | --- | --- |
| Pruebas | [Instalador de SGC Pruebas](https://github.com/GrupoGlobal-EC/sgc-desktop-releases/releases/download/staging/SGC.Pruebas-staging-Setup.exe) | [Canal de pruebas](https://github.com/GrupoGlobal-EC/sgc-desktop-releases/releases/tag/staging) |
| Produccion actual (ClickOnce) | [Instalador actual](https://grupoglobal.ec/descargas/sgc/instalador.html) | La nueva edicion se habilitara despues del piloto |

La primera instalacion de la nueva edicion se hace con este instalador. Despues, las actualizaciones
se pueden descargar desde la aplicacion, en **Ayuda > Buscar actualizacion**.
Guarda tu trabajo antes de reiniciar para aplicar una actualizacion.

La edicion de pruebas puede mostrar un aviso de editor no verificado mientras se configura la firma.
Verifica que la descarga procede de esta organizacion. Conserva el acceso de ClickOnce hasta que
Sistemas confirme la nueva instalacion.

Soporte: sistemas@grupoglobal.ec
